# 推し活　第一章「初次約會」

日本黑色幽默恐怖遊戲。胖廚師健太為了讓變成殭屍的偶像星野美月恢復原貌，白天潛入殭屍街道和人類營地帶回「食材」，晚上在餐廳做料理餵她。

## 怎麼玩
直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages 後用網址遊玩。電腦和手機（橫放）都可以玩。

| 操作 | 電腦 | 手機 |
|---|---|---|
| 餐廳移動 | A／D 或方向鍵 | 左下 ◀ ▶ |
| 出擊移動 | WASD | 虛擬搖桿 |
| 互動、裝袋、撿東西 | E | 互動鍵 |
| 擀麵棍 | 滑鼠左鍵／J | 攻擊鍵 |
| 放下袋子 | Q | 放袋鍵 |
| 奔跑 | Shift | 奔跑鍵 |
| 丟石頭 | F | 投石鍵 |
| 地圖 | M | 地圖鍵 |
| 暫停（存檔、回主選單） | Esc | 右上 Ⅱ |

## 第一章流程
序章漫畫 → 夜晚餐廳聽廣播 → 白天出擊殭屍商店街 → 潛入便利商店敲昏人類、裝進黑袋 → 從後門撤退 → 冷凍櫃湊滿 5 人 → 料理「初戀的心跳漢堡排」→ 冷藏室餵食 → 第一章完成

存檔放在瀏覽器（localStorage），主選單可以「繼續玩／重新開始／讀取進度」，餐廳暫停選單可以手動存到 3 個欄位。

## 開啟 GitHub Pages
Repository → Settings → Pages → Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾 `/ (root)` → Save。等一兩分鐘就會出現遊戲網址。

## 檔案結構
- `index.html`、`style.css`：遊戲頁面
- `js/`：程式（`config.js`、`sortie_config.js`、`cook.js`、`story.js` 是可以改數值、台詞、圖片的設定檔）
- `assets/`：圖片與音樂
